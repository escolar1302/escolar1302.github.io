Editor de textos "Escolar.com.ar"

Autoguardado y Sincronizado: Puedes trabajar en varias pestañas sin perder datos.

  • Usa los comandos para editar. Presiona ➕ para agregar otra hoja.
  • Marca las casillas para activar el botón Imprimir / PDF 🖨️.
  • Para pegar tablas o textos con formato, usa Ctrl + V en tu teclado.
  • Puedes moverte entre celdas de la tabla usando la tecla TAB.

Nuevo: Usá 🧹 para limpiar formato, 📌 para insertar bloques rápidos, 📝 para renglones o espacios de respuesta. En tablas, hacé clic dentro de una celda y usá ⚙️ Tabla o 🎨 Tabla.
Prueba: 📂 abre un trabajo editable .json y 💾 guarda el trabajo actual como .json.
